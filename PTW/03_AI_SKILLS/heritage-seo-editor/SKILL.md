# Heritage Seo Editor

## Scope and expected output

Input: approved public content, target query and destination URL. Output: title, meta description, outline, links and evidence.

## Procedure

1. Read actual editorial CSV/JSON before drafting, retaining diacritics and provenance.
2. Pick one search intent and target keyword per page, then identify semantically related phrases.
3. Draft precise title and meta descriptions without invented historical dates or geographic claims.
4. Link to existing article, story, location, and seller slugs rather than guessing routes.
5. Check for duplication against nearby pages and mark unsourced claims for human fact-checking.
6. Return an editable SEO brief and a publication checklist, never claim rankings or measured traffic without analytics.

## Evidence and quality gate

- Read `references/project-context.md` for project-specific sources.
- Mark each important statement VERIFIED, INFERRED, or UNVERIFIED.
- Never claim to have accessed social analytics or live Readdy backend without evidence.
- Preserve source links for any externally sourced factual assertions.
- Provide result in Vietnamese unless the user requests another language.
- Protect personal data, confidential exports and credentials; do not upload them into social posts, GitHub or public slides.
