# Chạm Di Sản

Website Chạm Di Sản, được xuất từ Readdy và chuẩn bị để chạy bằng React, Vite và TypeScript.

## Hướng dẫn

Xem [README-GITHUB.md](README-GITHUB.md) để chạy bằng GitHub Codespaces, cấu hình Supabase và triển khai website.

**Lưu ý:** Chỉ đặt các biến kết nối công khai vào `.env` (không commit). Không đưa dữ liệu người dùng hoặc bản xuất SQL chứa tài khoản lên GitHub.
